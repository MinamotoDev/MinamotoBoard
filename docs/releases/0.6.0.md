## Downloads

- `MinamotoBoard.msi`: Installer with plugin support.
- `MinamotoBoard-no-plugins.exe`: Portable EXE without plugin support.

## New Features and Bug Fixes

- Reworked how drawing instruments work.
- Added solid and dashed line options for the pen and highlighter.
- Improved the UI.
- Fixed known issues.
- Added pixel and stroke erasing modes.
- Improved the installation process.
- Added support for multiple languages.

## System Requirements and Dependencies

- 64-bit Windows 10 22H2 or later.
- .NET Framework 4.8 or later.
