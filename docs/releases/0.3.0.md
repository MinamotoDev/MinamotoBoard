# MinamotoBoard 0.3.0 · 本地预览

本版本仅在本地构建，尚未发布至 GitHub。

## 同版本本地修复

- 保持 **0.3.0**：改用官方 WiX 标准 Windows Installer 向导的默认布局、图片与中文文案，删除自绘对话框和额外说明。安装前确认，已安装时选择“修复”或“删除”，删除前再确认；新包覆盖旧包使用更新确认页。
- 原生 Windows Installer 注册仍保留，补全安装位置；不额外创建手工卸载注册项或独立卸载程序，不添加开始菜单卸载项。
- 白板启动项改为独立组件中的普通快捷方式，允许同版本覆盖重建入口；升级的旧包移除放入可回滚事务。
- 工具栏改为单行并取消 1120 DIP 宽度上限，居中按内容收紧。逻辑视口较大时适度缩小，最大缩小约 10%，内置常用控件点击区域保持至少 45 DIP。
- 窄屏或插件按钮过多时横向滚动，支持触摸滑动和左右按钮，避免换成多行或无限缩小按钮。
- 按 Windows 的 DIP 和 DPI 布局，未对物理像素尺寸作固定假设。实际大屏效果和安装/升级/卸载流程尚未运行测试。

## 新功能

- **加页**：在当前页之后插入空白页并立即切换，原有页面和笔迹保留。
- **上一页 / 下一页**：切换页面，中间显示当前页码和总页数；首尾页相应按钮不可用。
- **清屏**：确认后只清空当前页面的笔迹，保留页面背景与其他页内容；空白页不弹确认。
- **关闭确认**：即使当前页为空，只要其他页还有笔迹，也会提示所有页面内容将丢失。

页面使用原生 StrokeCollection 独立保留笔迹，不为每页生成位图，也不复制整个画布。
新增页面继承当前背景；切换页面保留当前所选画笔颜色、宽度和橡皮大小。
最多 100 页，达到上限后停用加页，防止无上限新增页面。单页笔迹量尚未设内存硬限制。
书写仍在捕获输入时不切换页面或清屏，以减少跨页误操作。

## 本地文件

- `artifacts/release-0.3.0/MinamotoBoard.msi`：含 Plugins 功能的标准安装版。
- `artifacts/release-0.3.0/MinamotoBoard-no-plugins.exe`：独立无插件版，同样提供加页和清屏。

默认安装目录仍为 `C:\Program Files\MinamotoDev\Board`，沿用选定的 v5 铅笔图标。
EXE、MSI 内部版本均为 0.3.0，未签名。

## 当前限制与构建范围

清屏目前不可撤销；尚无文件保存、自动恢复、撤销/重做和删除页面功能。
关闭程序或程序异常退出会丢失所有页面；请勿将当前版本用于必须持久保留的课堂记录。
第三方插件自己的覆盖层不属于原生页面笔迹，不随清屏删除，也不自动按页保存；插件缓存笔迹时应重新读取 `host.Canvas.Strokes`。

本次按用户此前要求只编译 Release 和打包，不运行自动化、界面、性能或安装测试。
未推送代码或创建 GitHub Release。此前版本的测试结果不代表 0.3.0 已通过运行验证。
