# MinamotoBoard 0.2.0

面向 Windows 10 22H2 x64 教学电脑的原生 WPF 白板，包含选定的铅笔图标。

## 下载

- **MinamotoBoard.msi**：标准安装版，包含 Plugins 功能，默认安装到 `C:\Program Files\MinamotoDev\Board`。安装需要管理员授权，正常运行不需要。
- **MinamotoBoard-no-plugins.exe**：免安装独立 EXE，编译时移除插件管理、加载代码与 PluginApi 引用；不显示 Plugins 按钮，不扫描插件目录，不需要插件 DLL 或额外配置文件。

两者均需要 **.NET Framework 4.8 或更高版本**，原版 Windows 10 22H2 已包含 4.8。
程序不包含现代 .NET 运行时，也不需要浏览器组件或联网运行。

## 功能

- 默认绿色画布、白色画笔、五种颜色和五档笔宽。
- 原生墨迹输入、可调橡皮、全屏切换与可隐藏工具栏。
- 标准安装版支持本机 DLL 插件扩展功能和 UI；插件通常位于 Windows 文档目录的 `MinamotoDev\Board\Plugins`。
- 使用最终确认的无文字、细铅笔图标。

## 当前限制

- 预览版尚未提供保存、撤销/重做和多页面功能，退出后笔迹会丢失。
- 文件未做代码签名。
- 本次按要求只完成构建和打包，未运行测试或安装验收；真实触屏、学校 Windows 10 与旧硬件表现仍待实机验证。

正式发布版本号统一为 **0.2.0**。此前本地预览包使用过 0.2.1；若安装过该本地包，请先从 Windows 应用列表卸载后再安装本版本，MSI 会阻止直接降级。卸载不删除用户插件目录。
