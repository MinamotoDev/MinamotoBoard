## Downloads

- `PalmGuard.Plugin.dll`: Touch input protection plugin for MinamotoBoard.

## New Features and Bug Fixes

- Adds single-contact writing and pause-on-multiple-contacts modes.
- Supports a movable, resizable touch exclusion area.

## System Requirements and Dependencies

- MinamotoBoard 0.6.0 with plugin support.
- 64-bit Windows 10 22H2 or later.
- .NET Framework 4.8.
