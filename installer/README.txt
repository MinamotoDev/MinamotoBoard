MinamotoBoard

System requirements and latest downloads:
https://github.com/MinamotoDev/MinamotoBoard/releases/latest
Installation requires administrator approval. Run the app as a standard user.
Open MinamotoBoard from the Start menu.

F11: toggle full screen. Esc: exit full screen. Ctrl+Tab: show/hide the toolbar.
Swipe up on a tool, or right-click it, to adjust its options.

Manage plugins in Settings > Plugins. Changes take effect after restart.
Plugin folder: Windows Documents\MinamotoDev\Board\Plugins.
Plugin settings: %LOCALAPPDATA%\MinamotoDev\Board.
Use trusted plugins only. See PLUGINS.md for development details.
Safe mode: MinamotoBoard.exe --safe-mode
Software rendering: MinamotoBoard.exe --software-rendering

Uninstall through Windows Settings, Control Panel, or Uninstall.exe.
Delete settings and plugins is unchecked by default. Selecting it removes
the current user's MinamotoDev\Board folders under Documents and local application data after a successful uninstall.

Documentation and language selection:
https://github.com/MinamotoDev/MinamotoBoard/blob/main/installer/README.md
