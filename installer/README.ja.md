# みなもとボードのインストーラー

[English](README.md) | **日本語** | [简体中文](README.zh-CN.md) | [正體中文](README.zh-TW.md)

## 動作環境

動作環境と依存関係は[最新版のリリース情報](https://github.com/MinamotoDev/MinamotoBoard/releases/latest)を参照してください。

インストールには管理者の許可が必要です。アプリは標準ユーザーとして実行します。

インストールとアンインストールには Windows の表示言語を使用します。英語、日本語、簡体字中国語、繁体字中国語に対応し、その他の言語では英語を使用します。

## 使い方

スタートメニューからみなもとボードを起動します。

- ページの追加・移動に対応します。
- ツールを上にスワイプするか右クリックすると、色・種類・太さを調整できます。
- ツールバーから作図用具を追加できます。ペンや蛍光ペンで辺に沿って描き、赤いボタンで作図用具を削除します。
- 定規と三角定規は本体をドラッグして移動し、青いハンドルでサイズと角度を調整します。
- コンパスは円の中心をドラッグして移動し、青いハンドルで半径を調整します。円形ガイドに沿って円弧を描けます。
- 塗りつぶしは閉じた領域が対象です。ページの消去は取り消せません。
- `F11`：全画面表示の切り替え。`Esc`：全画面表示を終了。`Ctrl+Tab`：ツールバーの表示・非表示。

## プラグインとアンインストール

**設定 → プラグイン**で管理します。変更は再起動後に反映されます。信頼できるプラグインのみ使用してください。

- プラグイン：Windows のドキュメント内の `MinamotoDev\Board\Plugins`。
- プラグイン設定：`%LOCALAPPDATA%\MinamotoDev\Board`。
- セーフモード：`MinamotoBoard.exe --safe-mode`。
- ソフトウェアレンダリング：`MinamotoBoard.exe --software-rendering`。

Windows の設定、コントロールパネル、またはインストール先の `Uninstall.exe` からアンインストールできます。**設定とプラグインを削除**は既定でオフです。選択すると、アンインストール成功後に現在のユーザーのドキュメントとローカルアプリデータ内の `MinamotoDev\Board` フォルダーを削除します。
